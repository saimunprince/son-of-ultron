# SYRAX feature catalog

What a JARVIS-class assistant does and where SYRAX stands: 71 features, HAVE 28 · PARTIAL 7 · TODO 30 · REJECTED 6.

Built 2026-10-12 from a survey of FatihMakes JARVIS assistants (ideas only): Mark-LV is CC BY-NC 4.0 and the other repositories carry no licence, so no code was taken; every feature is built SYRAX's way (permissions, tests, the gate, the journal).

A TODO becomes an objective with its own machine check (`feature_promote` over WebSocket). Entries marked **auto** are low risk, need nothing new and fit in a skill, so SYRAX may take them up itself when it is idle. Anything that needs a new dependency, a key or the owner's decision waits for the owner.

Generated by `python -m syrax.catalog`; edit `backend/syrax/catalog.py`, not this file.
